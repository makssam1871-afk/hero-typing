# Печать Героя — Тренажёр слепой печати с геймификацией
Решение отборочного этапа хакатона «Киберрывок» (Осень 2026).

## Реализованный функционал
1. **4 режима печати и 2 языка (RU/EN):** Слова (2–10 букв), Предложения, Код (Python, JS, HTML) и Спецсимволы.
2. **Обучение и эргономика:** Интерактивная экранная клавиатура с цветовой разметкой зон пальцев и динамическими подсказками для каждого следующего символа.
3. **Геймификация:** Очки опыта (XP), уровни, множители комбо (x2, x3, x5), временные бонусы во время печати (+50% к скорости, x2 опыта на 10 сек), 5 достижений, звуковой движок (Web Audio API) и система частиц (Canvas).
4. **Аналитика и аккаунты:** Синхронизация прогресса через SQLite, анализ «проблемных» клавиш, графики динамики скорости и точности (Chart.js).
5. **Таблица лидеров:** Рейтинги по скорости (WPM/CPM), точности и опыту с фильтрацией за день, неделю и всё время.

## Технологический стек
* **Backend:** Python 3.10+, FastAPI, SQLAlchemy, SQLite
* **Frontend:** HTML5, TailwindCSS, Vanilla JS, Chart.js
